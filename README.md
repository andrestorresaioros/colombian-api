# colombian_api

Prueba técnica en JavaScript: consumo de la API pública [api-colombia.com](https://api-colombia.com/) y procesamiento de la información obtenida.

## Contenido

- Consulta de presidentes, aeropuertos, atracciones turísticas, departamentos y regiones de Colombia.
- Agrupación y procesamiento de los datos obtenidos (por ejemplo, presidentes por partido político, aeropuertos y atracciones turísticas por departamento/ciudad).
- `prueba.js` — funciones de consumo y procesamiento de la API.

## Ejecución

Abrir `prueba.js` en un entorno con `fetch` disponible (navegador o Node.js con soporte de `fetch`) y ejecutar las funciones deseadas.
